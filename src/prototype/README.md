# Prototype

The interactive CarPlay demo. Composes the system chrome, the Master Orb,
the Magnifier provider, the Phone app surface, and the Maps/Music sketches.

- `chrome/` is the CarPlay system frame: status bar, left dock, orb home
- `MasterOrb/` is the orb itself, state machine, dissipation, aura
- `Magnifier/` is the context-aware magnifier provider plus useMagnifiable hook
- `phone/` is the Phone app surface (tabs, contact rows, radial dialer)
- `surfaces/` is Maps and Music sketch surfaces
